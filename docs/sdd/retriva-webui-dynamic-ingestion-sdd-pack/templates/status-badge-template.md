# Source Status Badge Mapping

```text
CREATED -> Configured
VALIDATING_CONNECTION -> Validating connection
BASELINE_PENDING -> Waiting for initial indexing
BASELINE_RUNNING -> Initial indexing
CATCHUP_RUNNING -> Catching up
ACTIVE -> Active
PAUSED -> Paused
DEGRADED -> Degraded
FAILED -> Failed
DELETING -> Disconnecting
DELETED -> Deleted
```

Badges must include text and not rely on color only.
