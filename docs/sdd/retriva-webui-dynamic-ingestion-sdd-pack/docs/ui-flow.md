# Connected Sources UI Flow

## Entry

```text
Ingestion page
  -> Static ingestion tab
  -> Connected Sources tab
```

## Create MediaWiki source

```text
Connected Sources
  -> Add source
  -> Select MediaWiki
  -> Enter connection details
  -> Configure scope
  -> Select target KB
  -> Configure sync policy
  -> Review
  -> Create
  -> Source detail shows BASELINE_PENDING or BASELINE_RUNNING
```

## Monitor source

```text
Source detail
  -> status card
  -> progress
  -> latest run
  -> run history
  -> errors
  -> actions
```

## Operate source

```text
Sync now
Pause
Resume
Disconnect/delete
```
